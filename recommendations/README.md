# Optional recommendations

The public starter installs only a reusable terminal and command-line baseline. These lists preserve useful application and specialist-tool suggestions without installing them automatically:

- [macOS applications](macos-apps.md)
- [specialist CLI tools](cli-tools.md)
- [optional uv tools](uv-tools.md)

Review each tool before adding it to a private Brewfile, Pixi manifest, or uv manifest. Accounts, tokens, provider settings, and application-specific state belong in private configuration, not in the public starter.
