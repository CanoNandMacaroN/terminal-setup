# Optional macOS applications

These applications are intentionally excluded from `starter/dot_Brewfile`. Install only the ones that match the machine's role.

## Terminals and agent workspaces

```sh
brew install --cask ghostty
brew tap manaflow-ai/cmux
brew install --cask cmux
```

## AI clients and configuration managers

```sh
brew install --cask codex
brew tap farion1231/ccswitch
brew install --cask cc-switch
brew tap stablyai/orca
brew install --cask orca
brew tap anomalyco/tap
brew install --cask sbx
```

## Desktop utilities

```sh
brew install --cask android-platform-tools
brew install --cask keka
brew install --cask monitorcontrol
brew install --cask spotify
brew install --cask switchhosts
```

Application configuration, login state, and credentials are not part of the public starter.
